# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

## 账户分片抽取（已落地 · 分片总批）

口径全局唯一：**乙 · 部分成功 + 未完成总批**。任一片失败时其它已成功片的本批快照**保留**；总批置 `未完成` 并列出失败片账户集合，禁止全量通过；失败片重跑补齐、覆盖与声明一致后才封成 `成功`。

| 接口 | 作用 |
| --- | --- |
| `POST /api/分片总批` | 按账户序切片开总批并跑片（可 `注入失败片序` 造夹具） |
| `POST /api/分片总批/{id}/运行片` | 单分片一写事务：成功落本片快照，失败本片零残留 |
| `POST /api/分片总批/{id}/封成` | 重跑全部未成功片，覆盖一致后封成成功 |
| `GET /api/分片总批/{id}/核证` | 各片状态、残留快照、可否当全量回放、`valid` |
| `POST /api/回放` | 带 `分片总批编号` 时范围锁定为声明账户集合；未完成总批拒绝全量，仅允许 `诊断` 且永不计通过 |

实体：`分片总批`（声明账户集合/状态/版本/可当全量回放）+ `分片任务`（每片账户集合/状态/快照数）。片提交与总批汇总靠 `版本` 闸失败闭，绝不汇总出缺片总批。

夹具：`账户分片-片二失败样例.json`（三片第二片失败）· `账户分片-补齐样例.json`（补齐封成）· `账户分片-交错并发样例.json`（片提交×汇总交错）。测试：`backend/tests/test_账户分片抽取.py`。
